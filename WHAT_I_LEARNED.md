# What I Learned

While working on this project, I learned several practical things about developing a Django application.

- I learned how to structure a Django project and work with Django apps, models, views, URLs, and templates.
- I got more practical experience with Django REST Framework and learned how to create APIs and validate API input.
- I learned how to create relationships between different models such as Product, Box, Order, and OrderItem.
- I learned how to separate the main business logic from the views and use it for calculating order weight and recommending a suitable box.
- I learned how product dimensions, weight, quantity, and product rotation can affect the box selection process.
- I got better at writing test cases and learned how to use Django's testing framework to find problems in the application.
- I also learned that debugging is an important part of development. During the project I faced some implementation errors, fixed them, and verified the changes by running the application and tests.
- Overall, this project gave me better practical understanding of connecting a Django backend, REST API, and frontend together in one application.
